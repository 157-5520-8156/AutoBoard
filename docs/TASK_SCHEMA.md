# 任务主表字段

开源版本不附带任何生产 Base。请先在飞书多维表格创建任务主表，并至少建立以下字段。
字段名称应保持一致；类型不一致时，初始化或健康检查会失败。

| 字段 | 建议类型 |
| --- | --- |
| 任务编号 | 文本（主字段） |
| 任务标题 | 文本 |
| 任务来源 | 单选 |
| 任务分类 | 单选 |
| 优先级 | 单选 |
| 督办领导 | 文本 |
| 承接部门 | 文本 |
| 负责人 | 文本 |
| 负责人（飞书成员） | 人员 |
| 计划开始时间 | 日期 |
| 截止时间 | 日期 |
| 下次跟进时间 | 日期 |
| 任务状态 | 单选 |
| 完成比例 | 数字 |
| Sprint | 文本 |
| 工作量点 | 数字 |
| 风险等级 | 单选 |
| 最新进展 | 文本 |
| 剩余事项 | 文本 |
| 当前卡点 | 文本 |
| 是否已通知 | 复选框 |
| 执行要求与标准依据 | 文本 |
| 前置关联任务 | 关联本表 |
| 佐证附件 | 附件 |
| 来源消息ID | 文本 |
| 最后更新时间 | 日期 |

任务进展表至少需要：更新标题、任务编号、任务标题、负责人、更新时间、本次进展、
完成比例、状态变更、下一步、当前卡点、更新人和来源消息ID。

`scripts/migrate-minister-board.mjs` 会补充协作字段和视图，但不会替你创建飞书应用或
选择业务选项。请先在测试 Base 运行无 `--apply` 的预览模式。
